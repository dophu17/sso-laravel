## 🚀 **QUICK START FOR OTHERS:**

```bash
# Clone
git clone https://github.com/dophu17/sso-laravel.git
cd sso-laravel

# Install
composer install
cp .env.example .env
php artisan key:generate

# Database
# Configure .env, then:
php artisan migrate
php artisan passport:keys --force
php artisan passport:client --personal

# Run
php artisan serve

# Visit
http://localhost:8000
```
